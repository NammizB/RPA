# Word Certificate Generator

## Overview

Generates one valid DOCX certificate per student by reading `input/students.csv` and replacing placeholders in a genuine Word Open XML template.

## Technologies and activities

- UiPath Studio Windows project and `UiPath.System.Activities`.
- `UiPath.Word.Activities` dependency is included for Studio compatibility.
- Portable Open XML ZIP processing is used from the UiPath-orchestrated runner; Microsoft Office Interop is not required.

## Inputs and outputs

- Input: `input/CertificateTemplate.docx`, generated by `Initialize.ps1`, plus `input/students.csv`.
- Outputs: `outputs/certificates/*.docx` and `outputs/verification.json`.

## Workflow

The workflow reads each CSV row, replaces `{{STUDENT_NAME}}`, `{{COURSE_NAME}}`, and `{{COMPLETION_DATE}}` in the DOCX document XML, writes a separate certificate, then opens the generated ZIP package and verifies the personalized name and required entries.

## Setup and PDF limitation

Run `Initialize.ps1` once, then run `Main.xaml`. PDF export is intentionally reported as unavailable because this portable project does not assume Microsoft Word or a PDF conversion engine. No PDF success is claimed.

## Verified test results

Direct runner and UiPath Robot PASS. Four DOCX certificates were generated, each personalized name was found in the output document XML, and all generated ZIP packages contained the required Word document part. PDF export remains explicitly unavailable in this portable runtime; no PDF success is claimed.
